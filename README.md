# Request to Brief

A Python project that helps turn a business request into a clearer project brief.

## Current features

- Asks for the project name, objective, intended users, and success criteria.
- Flags missing objectives, users, and success criteria.
- Displays a brief in the terminal.

## Run it

With Python 3 installed, download brief.py, open a terminal in its folder, and run:

```bash
python3 brief.py
```

## Project status

This is an early learning prototype. It checks whether information is present;
it does not yet assess its quality or use AI.
